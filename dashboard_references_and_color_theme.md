# Dashboard References & Color Theme

## Dashboard Style
The dashboard will follow a clean and professional SaaS/E-Commerce analytics style with consistent colors, simple layouts, and clear data visualizations.

## Selected Color Theme

| Usage | Color | Hex Code |
|---|---|---|
| Primary | Navy Blue | #1F4E78 |
| Secondary | Teal | #2A9D8F |
| Accent | Green | #52B788 |
| Highlight | Amber | #F4A261 |
| Background | Light Gray | #F5F7FA |
| Cards | White | #FFFFFF |
| Text | Dark Gray | #263238 |

## Retention Heatmap Theme

The Cohort Retention Heatmap will use a sequential Teal color scale:

Light Teal → Medium Teal → Teal → Dark Teal

This color scale will help users quickly identify high-retention and low-retention cohorts.

## Design Consistency

The same color palette, fonts, card styles, and spacing will be maintained across all four dashboard pages:

1. Executive Overview
2. Cohort Retention Analysis
3. CLTV Analysis
4. Customer Segmentation
