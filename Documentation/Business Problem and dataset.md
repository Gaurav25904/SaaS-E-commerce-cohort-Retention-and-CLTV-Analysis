

 Business Problem
The goal is to analyze customer retention and calculate Customer Lifetime Value (CLTV).

Businesses often spend more on acquiring customers than retaining them. This project focuses on:
- Identifying churn patterns
- Understanding customer retention behavior
- Improving long-term profitability

 Objectives
- Perform Cohort Analysis
- Calculate retention rates
- Build CLTV model
- Identify high-value customers

Dataset Overview
Dataset: Online Retail (2010–2011)

Columns:
- Invoice: Transaction ID
- StockCode: Product code
- Description: Product name
- Quantity: Number of items purchased
- InvoiceDate: Date of transaction
- UnitPrice: Price per item
- CustomerID: Unique customer ID
- Country: Customer location

 Initial Observations
- Dataset contains transactional data
- Suitable for cohort analysis
- Some missing values may exist
- Requires cleaning before analysis

 Next Steps
- Data cleaning
- Handling missing values
- Creating cohort groups
- Building retention matrix
