# Dashboard Testing

## Objective
Verify that the Power BI dashboard functions correctly and displays accurate information.

## Testing Checklist

### Data Validation
- Verify Total Revenue.
- Verify Total Customers.
- Verify Total Orders.
- Validate CLTV calculations.
- Check Retention Rate values.

### Visual Testing
- Confirm all charts display correctly.
- Verify KPI cards show accurate values.
- Check Cohort Retention Heatmap formatting.
- Ensure Customer Segmentation visuals are correct.

### Interaction Testing
- Test all slicers and filters.
- Verify cross-filtering between visuals.
- Check page navigation.
- Reset filters and confirm dashboard updates.

### Performance Testing
- Ensure visuals load without errors.
- Verify report responsiveness.
- Confirm DAX measures calculate correctly.

## Result
All dashboard pages, visuals, and KPIs were tested successfully. The dashboard is ready for presentation and project submission.
