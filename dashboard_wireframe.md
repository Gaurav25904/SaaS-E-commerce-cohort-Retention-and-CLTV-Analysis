# Dashboard Wireframe

The Power BI dashboard is planned with five pages:

## Page 1: Executive Overview
- KPI Cards
- Revenue Trend
- Customer Trend
- Segment Comparison
- Slicers

## Page 2: Cohort Retention Analysis
- Cohort Retention Heatmap
- Retention Decay Line Chart
- Cohort Size Chart
- Slicers

## Page 3: CLTV Analysis
- CLTV KPI Cards
- CLTV by Segment
- Average Order Value Chart
- Purchase Frequency Chart
- Slicers

## Page 4: Customer Segmentation
- Segment Distribution
- Revenue Contribution by Segment
- CLTV Comparison
- Slicers

## Page 5: Insights & Recommendations
- Key Findings
- Business Recommendations

The wireframe will maintain a consistent layout, theme, spacing, and navigation across all dashboard pages.
